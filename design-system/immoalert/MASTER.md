## Style Guidelines

**Style:** Exaggerated Minimalism

**Keywords:** Bold minimalism, oversized typography, high contrast, negative space, loud minimal, statement design

**Best For:** Fashion, architecture, portfolios, agency landing pages, luxury brands, editorial

**Key Effects:** font-size: clamp(3rem 10vw 12rem), font-weight: 900, letter-spacing: -0.05em, massive whitespace

### Page Pattern

**Pattern Name:** Marketplace / Directory

- **Conversion Strategy:**  map hover pins,  card carousel, Search bar is the CTA. Reduce friction to search. Popular searches suggestions.
- **CTA Placement:** Hero Search Bar + Navbar 'List your item'
- **Section Order:** 1. Hero (Search focused), 2. Categories, 3. Featured Listings, 4. Trust/Safety, 5. CTA (Become a host/seller)

## Anti-Patterns (Do NOT Use)

- ❌ Poor photos
- ❌ No virtual tours

### Additional Forbidden Patterns

- ❌ **Emojis as icons** — Use SVG icons (Heroicons, Lucide, Simple Icons)
- ❌ **Missing cursor:pointer** — All clickable elements must have cursor:pointer
- ❌ **Layout-shifting hovers** — Avoid scale transforms that shift layout
- ❌ **Low contrast text** — Maintain 4.5:1 minimum contrast ratio
- ❌ **Instant state changes** — Always use transitions (150-300ms)
- ❌ **Invisible focus states** — Focus states must be visible for a11y

---

## Pre-Delivery Checklist

Before delivering any UI code, verify:

- [ ] No emojis used as icons (use SVG instead)
- [ ] All icons from consistent icon set (Heroicons/Lucide)
- [ ] `cursor-pointer` on all clickable elements
- [ ] Hover states with smooth transitions (150-300ms)
- [ ] Light mode: text contrast 4.5:1 minimum
- [ ] Focus states visible for keyboard navigation
- [ ] `prefers-reduced-motion` respected
- [ ] Responsive: 375px, 768px, 1024px, 1440px
- [ ] No content hidden behind fixed navbars
- [ ] No horizontal scroll on mobile

## Direction retenue pour la refonte du 26 octobre 2026

Les recommandations automatiques constituent un point de départ. La palette turquoise et les polices Cinzel/Josefin sont remplacées par une direction éditoriale adaptée à un outil de recherche quotidien.

- Toile ivoire `#f7f5f0`, surface `#fffefa`, encre `#272923`, texte secondaire `#67695f`, accent terre cuite `#a6412c`, séparateurs `#deded4`. Tous les textes courants visent 4,5:1 minimum.
- Manrope 400/500/600 pour les contrôles et contenus ; Newsreader 400/500 pour les grands titres. Échelle limitée : 12, 14, 16, 20, 32, 64 px (titre public adapté au viewport). Corps mobile 16 px.
- Navigation principale horizontale sur ordinateur, barre inférieure à quatre entrées et menu explicite sur mobile. Annonces avant statistiques. Deux annonces par rangée sur ordinateur, une sur mobile.
- Surfaces plates, séparateurs utiles, aucun empilement de cartes de statistiques. Pas de titres décoratifs en majuscules ni de pastilles clignotantes.
- Recherche enregistrée en deux étapes : lieu/budget puis critères facultatifs. Le récapitulatif reste visible ; les valeurs sont conservées en revenant en arrière.
- Animations uniquement transform/opacity : ouverture 260 ms, fermeture 150 ms, navigation 220 ms ; stagger total inférieur à 200 ms. Les mises à jour de polling ne rejouent pas les animations. `prefers-reduced-motion` annule les déplacements.
- Toutes les actions restent accessibles au clavier ; zones tactiles de 44 px ; état sélectionné textuel et sémantique ; erreurs au plus près du formulaire.
- Les comptes, les recherches, les alertes, les clés API et le déploiement PHP existants restent raccordés aux mêmes API.
