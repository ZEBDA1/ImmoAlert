# Visuels du README

[Retour au README](../../README.md)

`banner.svg` et `telegram-preview.svg` sont des illustrations vectorielles créées pour ImmoAlert. Elles sont versionnées dans le dépôt, sans police distante, script, ressource externe ni identifiant de compte.

La palette reprend le violet du profil de ZEBDA, complété par des accents cyan inspirés de Telegram. La bannière associe un radar immobilier à une carte d’annonce ; l’aperçu présente le panneau et une alerte.

Les textes des commandes et des boutons sont repris de `bot/keyboards.py` et `services/notification.py`. Le bien, son prix, sa surface et son emplacement sont fictifs. Les fichiers ne sont pas des captures d’écran de Telegram et ne représentent pas un bien actuellement proposé.

Les SVG peuvent être ouverts dans un navigateur ou un éditeur vectoriel. Les attributs `viewBox` permettent leur affichage à la largeur du README GitHub.
